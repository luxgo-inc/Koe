# Koe

自分専用の macOS 音声入力アプリ（superwhisper 代替）。日本語・AIエージェント入力特化。

- F9: 素のまま録音（タップでトグル / 押しっぱなしPTT）
- F10: AI整形録音（設定でON時のみ。Claude API でフィラー除去・整形）
- Esc: キャンセル（AI整形中は素のまま挿入）

## ビルドとインストール

```bash
bash scripts/build-app.sh --install
```

## 初回セットアップ

1. 起動 → メニューバーのマイクアイコン → 「権限の状態を確認…」
2. マイク / 入力監視 / アクセシビリティ を許可 → Koe 再起動
3. AI整形を使う場合: 設定 → APIキー保存 → メニューの「AI整形を有効にする」を ON

## v2 機能

- **ポップオーバーメニュー**: モード表示・AI整形トグル・プリセット切替・直近3件コピー・権限バナー
- **履歴ビューア**: 検索・コピー・削除・全削除（履歴保存はデフォルトON、設定でOFF可）
- **置換辞書**: 「いーすぺーす→E-Space」等の固定置換（AI整形の前・素のままでも適用）
- **プロンプトプリセット**: 整形プロンプトを複数保存・切替
- **キーキャプチャ**: 設定でキーを押してホットキー変更
- **アップデート確認**: メニューから git 差分確認 → Terminal で更新

## 会議録音モード（v3）

Google Meet / Zoom 等の会議を、マイク（自分）＋システム音声（相手）の2系統でローカル文字起こしし、話者別タイムスタンプ付きの議事録 Markdown を保存する。

- **開始/停止**: メニューバーのポップオーバー →「会議録音を開始」/「停止して保存」（録音中はアイコンが ●、経過時間表示）
- **保存先**: `~/Library/Application Support/Koe/meetings/YYYY-MM-DD-HHmm-meeting.md`（保存後 Finder で自動表示。「議事録フォルダを開く」からも辿れる）
- **AI要約**: 「AI整形」トグルがONのとき、議事録冒頭に決定事項/TODO/論点の要約を付与（Claude API・従量課金）。OFFなら完全オンデバイスで完結
- **権限**: 初回にシステム音声録音の TCC 許可が必要（Info.plist `NSAudioCaptureUsageDescription`）
- **安全弁**: 3時間で自動停止・保存
- **注意**: 会議の録音・文字起こしは相手の同意を得てから行うこと（冒頭で「記録します」と一言）

### 会議録音スモークテスト

1. 「会議録音を開始」→ 初回はシステム音声録音の TCC プロンプト → 許可
2. YouTube 等で日本語音声を再生しつつ自分でも喋る → 停止して保存
3. Markdown に `[mm:ss] **自分**/**相手**` のセグメントが時刻順で入っている
4. AI整形ONで再テスト → 冒頭に要約セクションが付く
5. 会議録音中に F9 の通常音声入力が併用できるか確認
